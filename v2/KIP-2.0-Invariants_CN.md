# KIP 2.0 不变量注册表 (Invariant Registry)

**[English](./KIP-2.0-Invariants.md) | [中文](./KIP-2.0-Invariants_CN.md)**

## 规范状态

**[KIP-2.0-SPECIFICATION_CN.md](./KIP-2.0-SPECIFICATION_CN.md) 与 [profiles/CognitiveMemoryProfile-2.0_CN.md](./profiles/CognitiveMemoryProfile-2.0_CN.md) 的规范性伴随文档，版本 2.0-draft**

本文档是 KIP 2.0 所要求的全部不变量的唯一定义清单。Part A 包含规范 §102 要求每一套合规实现必须遵守的 38 条跨领域核心不变量（Core invariants）；Part B 包含认知记忆 Profile（Profile §23）的 35 条不变量，对声明支持该 Profile 的实现具有约束力。编号保持稳定：核心不变量沿用 §102 赋予的编号，因此 `§102 invariant 17` 与一致性测试套件的覆盖矩阵（§27）保持解析有效；Profile 不变量以 `P` 加上 Profile §23 赋予的编号表示。

表格中的每一行标明了确立该不变量的规范章节 —— 裸写 `§` 指向核心规范，`Profile §` 指向认知记忆 Profile —— 以及钉住该不变量的一致性测试向量。没有测试向量的核心不变量在规范上是不存在的：[conformance/KIP-2.0-Conformance-Tests.md](./conformance/KIP-2.0-Conformance-Tests.md) §27 中的覆盖矩阵是 Part A 的权威依据，在此仅为阅读方便而重述。标为 `—` 的 Profile 不变量由 Profile 的正文散文所要求，目前尚未由可移植测试向量钉住。

仅当规范或 Profile 的修订确立了新的不变量时，才可在此处增补，绝不能仅由本文档自行新增；确立章节先行修订，本表记录随之更新。

## 两部分的协同阅读

```text
Core 不变量      协议层真理：在任何 Space、任何 Profile 下均无条件成立
Profile 不变量   记忆层真理：在激活了认知记忆 Profile 的环境下成立
```

Profile 中的若干条款是用 Profile 的专门词汇对 Core 条款的具体重述 —— 如 P3 与 15、P11 与 10、P26 与 36、P32/P33 与 37 —— 这种重述是刻意为之的：Core 条款约束底层运行时，Profile 条款约束通过该运行时进行读写的大脑策略。Core 条款永远不依赖 Profile 条款。
